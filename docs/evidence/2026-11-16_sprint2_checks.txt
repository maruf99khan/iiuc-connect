Bug found and fixed by that run
  Next.js reported 'unstable value Date.now() while prerendering' for /dashboard,
  /sign-in and /sign-up in development. Cause: Supabase's session check reads the
  clock and Cache Components forbids that inside the prerendered shell. Fix:
  `await io()` at the top of getCurrentUser() (lib/auth/session.ts). The error
  no longer appears. (The production build had passed with the bug present, so
  only a browser run could have found it.)
