How to read these
  - Google's lab thresholds for LCP are 2.5 s good and 4 s poor. Those thresholds are meant for real
    users' 75th percentile, not for a deliberately throttled lab run, so the Slow 3G figure is a
    stress result, not a verdict on the site.
  - On Slow 3G, 2.0 s of the 4.9 s is the first byte, and the throttle itself adds a fixed round
    trip to every request.

A finding to follow up (a hypothesis, not yet measured)
  - Vercel served this request from region iad1 (US East; response header x-vercel-id), while the
    Supabase project is in Singapore (Build_State). Every server-side query from a signed-in page
    therefore crosses the world, which would add a round trip per query. Moving the functions to
    Singapore (sin1) is a one-line vercel.json "regions" setting. Measure a signed-in page before
    and after to find out whether it matters.
