Problems found while building, and how they were handled
  1. A request could target a private graduate's slot (found while writing the
     plan). The insert policy now requires the slot to be visible to the caller.
  2. That policy and the slot policy referenced each other; Postgres reports any
     cycle between two tables' policies as "infinite recursion", even for
     different commands. Migration 009b moves the check into a SECURITY DEFINER
     function (private.is_slot_requester), which is not expanded into the outer
     query.
  3. Three of 88 early test assertions failed (46, 49, 70) because a BEFORE row
     trigger refuses before row-level security checks the row; the expected
     error codes were corrected, not the code under test.
  4. CI failed twice for reasons unrelated to the schema: the test tail printed
     only failures so pg_prove saw "planned 97 tests but ran 0"; and the
     supabase/setup-cli step hit the GitHub API rate limit resolving "latest"
     (CLI now pinned to 3.3.0).
  5. After the browser run: an accepted request whose session had already
     closed still offered "Cancel session". The page now offers it only while
     a scheduled session exists.
