What was built
  Database   profiles.portfolio_url and github_url (https only; GitHub host fixed to github.com
             or www.github.com; portfolio host may not carry credentials).
             job_applications.cv_path (nullable), constraint applications_cv_path_shape:
             cv_path = applicant_id/application_id.pdf. Insert grant widened to id and cv_path;
             cv_path cannot be updated.
             Private bucket application-cvs: PDF only, 2 MB. Upload policy: verified member, own
             folder, name must be a uuid + .pdf. Read policy via private.can_read_cv(): the
             applicant, or the poster of the job while the application is not withdrawn.
             Admins cannot read CV files (decision D-025).
             public.cv_purge_candidates(limit): service role only; lists orphan files (over a day
             old, no application) and files of applications withdrawn over a day ago.
  App        lib/jobs/cv.ts (file check by content, path builder), lib/jobs/cv-purge.ts,
             apply form with optional CV and a private-profile note, poster list with a profile
             link and "Open CV", route /jobs/[id]/cv/[applicationId] (makes a 60-second signed
             link on click), profile form fields, member page links (shown only if they pass the
             same https check), cron route now also removes CV files.
