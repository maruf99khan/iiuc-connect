Found and fixed during the sprint
  1. Members could edit the department, batch and graduation year an admin had
     approved (a Sprint 1 grant). Revoked; the verified name is locked by trigger.
  2. The database accepted any https LinkedIn address, so a member calling the
     API directly could show an arbitrary link on their profile. Tightened.
  3. The 'public' visibility was labelled 'Anyone signed in' while the database
     lets visitors who are not signed in read it. The label now says so.
  4. A page past the end of the results said 'No members match'. Now it says
     there is no such page.
  5. Test-only: label selectors matched more than one element.
